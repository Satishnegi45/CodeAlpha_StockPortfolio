# Stock Portfolio Tracker

This is a simple stock portfolio tracker made using Python.

## About the Project

The program allows the user to enter stock names and quantities. It uses predefined stock prices to calculate the total investment value.

## Features

- Predefined stock prices
- User can enter stock name
- User can enter quantity
- Calculates investment for each stock
- Calculates total investment
- Checks if the entered stock is available

## Stocks Used

- TCS
- INFY
- RELIANCE
- HDFCBANK
- ITC

## Concepts Used

- Dictionary
- Input and output
- Arithmetic operations
- While loop
- If-else statements
- For loop
